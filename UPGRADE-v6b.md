# v6b — Source UI Panel

Phase B now has a first visible source workflow.

## Added

- Course Map source panel.
- Linked-source count and source chips.
- Add Source modal.
- Pasted text/markdown source creation from the UI.
- Existing source registry list inside the modal.
- Link existing source to a course as `supplemental`.
- New source creation links as `primary`.

## Still intentionally missing

- Source parsing and chunking.
- Qdrant indexing.
- RAG lesson generation.
- Persistent interaction answers.

This patch only exposes the registry built in v11/v12.
